Option A — Cloudflare Pages

  1. Download the website ZIP above. It contains index.html, index.htm, the other HTML pages and their asset folders.
  2. Log in to Cloudflare, open Workers & Pages, and create or open a Pages project with Direct Upload.
  3. Upload the downloaded ZIP (or the extracted website folder), then deploy. Keep all the files at the site root, not inside an extra folder.
  4. Open the published homepage and test the mirror buttons, images and collection links.

Official Cloudflare Pages guide

Option B — FreeWHA / traditional FTP hosting

  1. Download the ZIP and extract it first on your computer.
  2. Connect to your hosting account using FileZilla or its web file manager.
  3. Upload all extracted files and folders into the public website root, preserving their names and relative paths. Do not upload only index.htm.
  4. Visit your domain. The index.html entry page opens index.htm automatically; both are included to accommodate different servers.
  5. Check GITHUB MIRROR and DOWNLOAD ZIP. The downloadable ZIP must remain in the same website root.

FreeWHA FAQ

Option C — GitHub Pages

  1. Download and extract the website ZIP.
  2. Sign in to GitHub, create a new public repository and upload all extracted files to its root. You may use GitHub Desktop to manage the repository.
  3. In the repository, open Settings → Pages; select Deploy from a branch, the main branch and /(root).
  4. Open your new GitHub Pages URL and verify that the site works.

Optional — Clone online

You can try a third-party web cloning service such as Pixellize. This service can omit pages or linked files, may show advertisements and is not controlled by Mega Book Collection. Do not install unrelated browser extensions to copy the site. The ZIP above is the more reliable option.

Important: This download is a snapshot, not an automatic synchronization service. After the original site changes, its owner must publish an updated ZIP. External URLs (for example, links to GitHub, Internet Archive or Zenodo) remain external: their files are not included. The download ZIP itself is not nested inside the archive to prevent recursive ZIP files; visitors running their own mirror should place a freshly created ZIP under the same filename in the website root.

Mirror maintenance

When you update a mirror, upload the revised HTML and resource folders together. Keep the relative paths unchanged. You may publish your own updated ZIP named MegaBookCollection-Website.zip for visitors.
