MEGA BOOK COLLECTION — WEBSITE MIRROR / CLOUDFLARE PAGES / FREEWHA
===================================================================

This package contains the COMPLETE STATIC WEBSITE COPY at the time it was made.

INDEX FILES
- index.htm : original Word-created homepage (editable source for later exports).
- index.html : tiny redirect to index.htm. Helps Cloudflare Pages and FreeWHA
  reliably open the same homepage from the domain's root URL.

MIRROR BUTTONS
- CLONE ONLINE: links to the external Pixellize service. It is optional and may
  show advertising; do not install an unrelated browser extension.
- GITHUB MIRROR: opens mirror-guide.html in this same website directory.
- DOWNLOAD ZIP: downloads MegaBookCollection-Website.zip in that same directory.

CLOUDFLARE PAGES
1. Upload the *outer deployment ZIP* or its extracted contents by Direct Upload.
2. Make sure index.html and index.htm are at the site root.
3. Test the published homepage and its buttons.

FREEWHA / FTP HOSTS
1. Extract the *outer deployment ZIP* on your computer.
2. Upload ALL extracted files and folders to your site's public root via FTP.
3. Do not upload the outer ZIP alone unless your File Manager extracts it there.
4. Make sure index.html, index.htm, mirror-guide.html and
   MegaBookCollection-Website.zip are in the same public root.

INDEPENDENT MIRROR ZIP
MegaBookCollection-Website.zip is a copy for visitors to download.
It does not include another copy of itself: this avoids endless recursive ZIPs.
Mirror owners should create/upload a new ZIP if they want to offer downloads.

The download is a snapshot, not an automatically updated backup. If the website
changes, the ZIP must be recreated and uploaded again.
External linked files on third-party sites are not included in this package.
No tables, colors or collection links were intentionally modified during this fix.


PERSONALIZE YOUR MIRROR WITH AI
- Open mirror-guide.html and find "CUSTOMIZE YOUR MIRROR WITH AI".
- Download the site ZIP, upload it to ChatGPT, and copy the supplied prompt.
- The goal is to redesign the appearance only, preserving tables, files and links.
- Check the result and publish the complete output to Cloudflare Pages or FreeWHA.
- The Copy prompt button works over HTTPS and includes a fallback for older browsers.
